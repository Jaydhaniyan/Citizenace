# 🇺🇸 CitizenAce — US Citizenship Test Preparation

CitizenAce is a modern web application designed to help users prepare for the **US Citizenship Civics Test** through interactive practice tests, flashcards, interview-style questions, and progress tracking.

🌐 **Live Demo:** https://citizenace.vercel.app/

---

## ✨ Features

- 📝 **Practice Test** — Take interactive US Citizenship civics practice tests.
- 🃏 **Flashcards** — Review important civics questions with interactive flashcards.
- 🤖 **AI Interview Practice** — Practice citizenship interview-style questions.
- 📊 **Dashboard** — View quiz results and track your practice progress.
- 🔐 **Google Authentication** — Secure login using Firebase Authentication.
- ☁️ **Firestore Database** — Store and retrieve user quiz results.
- 📱 **Responsive Design** — Works across desktop, tablet, and mobile devices.
- 🎨 **Modern UI** — Premium dark SaaS-style interface with responsive animations.
